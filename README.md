# カーショップグローリー｜スーパーカー買取LP

フェラーリ・ランボルギーニ・ポルシェ・マクラーレン・メルセデスAMG・BMW・アウディ・レクサス・ロータス、そしてネオクラシックまで幅広く対応する、スーパーカー買取専門のランディングページです。

参考サイトのレイアウト・配色・アニメーションの雰囲気を踏襲しつつ、スーパーカーらしい高級感（ダーク＋ゴールド＋レッドアクセント）を加えた完全オリジナルデザインで制作しています。

## 構成

- `index.html` — ページ本体（起承転結のLP構成）
- `css/style.css` — スタイル・レスポンシブ・CSSアニメーション
- `js/main.js` — 買取実績カルーセル / スクロールリベール / カウントアップ / フォーム制御
- `images/` — 画像格納フォルダ（後日差し替え）

## セクション

1. ヘッダー（固定・累計台数カウンター・電話/スピード査定CTA）
2. ヒーロー（買取金額UP! / スーパーカー画像コラージュ）
3. トラストバー（満足度・全国対応・査定無料）
4. 対応ブランド（+ ネオクラシック強化買取バナー）
5. 買取実績ギャラリー（カルーセル）
6. 高く売れる3つの理由
7. お客様の声
8. 買取の流れ（STEP.01〜05）
9. 買取査定フォーム（写真アップロード各種項目 → LINE誘導）
10. 会社概要
11. フッター / モバイル固定CTA

## 画像の差し替え方法

`images/` フォルダに画像を入れ、各プレースホルダー（`IMAGE` / `CAR PHOTO` / `SUPERCAR IMAGE n` と表示されている `.img-slot` `.car-slot`）を `<img>` に置き換えてください。CSSクラスはそのまま利用できます。

買取実績カードの内容は `js/main.js` 内の `results` 配列を編集すると更新できます。

## フォームについて

現状はフロントUIのみで、送信は「LINE誘導 + 完了メッセージ表示」の挙動です。実際のメール送信やバックエンド連携は未接続です（後日対応可）。
